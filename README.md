# EduGenie - AI Study Assistant

EduGenie is a Generative AI-powered educational assistant built using Python, Google Gemini API, and Streamlit.

## Features
- Summarizes study materials and topics instantly
- Answers subject questions with detailed explanations
- Generates quick quiz/review points for students

## Tech Stack
- Python
- Google Generative AI (Gemini)
- Streamlit
